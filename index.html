    주변 프레임 경계 확인: 바로 앞 칸은 아직 가능, 표시한 칸부터 불가능

    짝 영상

    작업자를 고르세요

    표시 규칙

    1. 프레임 번호는 원본 60 fps 기준, 0 부터 (영상 시작 = 0). 화면 왼쪽 위 F 숫자가 그 번호입니다.
    2. 시작 = 위반이 처음 보이는 프레임. 사라지기 시작 · 바뀌기 시작 · 통과하기 시작 · 순간이동한 첫 프레임. 바로 앞 프레임까지는 아직 가능한 장면이어야 합니다.
    3. 끝 = 위반이 끝나는 프레임. 순간적인 사건이면 시작과 같게 (I).
    4. 위반이 가림막 뒤에서 일어나 드러나는 순간이 따로 있으면, 시작은 드러나는 프레임으로 하고 “가림 뒤” 를 체크합니다.
    5. 위반을 못 찾겠으면 비워 두고 “못 찾음” 체크 + 메모에 이유.

    condition 별로 보는 것

    작업 순서

    1. 1× 로 한 번 끝까지 보며 위반이 대략 어디인지 찾습니다.
    2. 그 근처에서 ← → 로 한 프레임씩 움직이며, 아래 주변 프레임 줄에서 “가능 → 불가능” 으로 바뀌는 경계를 찾습니다.
    3. S 로 시작, E 로 끝을 찍고, R 로 구간을 다시 재생해 확인합니다.
    4. Enter 로 다음 영상. 라벨은 자동 저장됩니다.
    5. 작업을 마칠 때마다 CSV 내보내기 로 파일을 받아 담당자에게 보냅니다. 브라우저 저장소는 다른 컴퓨터 · 브라우저와 공유되지 않습니다.
    1. 프레임 번호는 15 fps 기준, 0 부터 (100 장이면 0–99). 화면 왼쪽 위 F 숫자가 그 번호이고, 원본 PNG 로는 scene_(F+1) 입니다.
    2. 가려지는 물체: 물체가 제자리에 있고 가림막이 올라와 가리면 정지, 물체가 움직여 가림막 뒤를 지나가면 움직임. 같은 쌍의 두 영상은 같은 값입니다.
    3. 불가능 영상: 시작 = 위반이 처음 보이는 프레임 (가림막이 걷히거나 물체가 나와서 이상하다고 판단할 수 있는 첫 프레임). 바로 앞 프레임까지는 아직 가능한 장면이어야 합니다. 끝 = 위반이 끝나는 프레임, 순간이면 시작과 같게 (I).
    4. 가능 영상: 위반은 없지만, 짝 불가능 영상에서 위반이 보이는 그 순간에 해당하는 같은 사건 구간을 같은 기준으로 찍습니다.
    5. 못 찾겠으면 비워 두고 “못 찾음” 체크 + 메모에 이유.

    쌍 보기

    1. 같은 쌍의 가능 · 불가능 영상은 위반 직전까지 같은 장면입니다. 짝 나란히 (C) 를 켜면 두 영상이 같은 프레임에 맞춰 움직입니다. 왼쪽 · 위가 가능, 오른쪽 · 아래가 불가능이고, 지금 라벨하는 영상에 파란 테두리가 있습니다.
    2. 목록은 묶음 → 쌍 → 불가능 · 가능 순서입니다. Enter 로 넘어가면 불가능 다음에 같은 쌍의 가능 영상이 나옵니다. X 는 짝 영상을 바로 엽니다.

    작업 순서

    1. 불가능 영상을 1× 로 끝까지 보며 위반이 어디쯤인지, 물체가 정지인지 움직이는지 봅니다 (Z / M).
    2. 그 근처에서 ← → 로 한 프레임씩 움직이며, 아래 두 줄에서 가능 · 불가능이 눈에 띄게 달라지는 경계를 찾습니다.
    3. S 로 시작, E 로 끝. Enter 로 같은 쌍의 가능 영상으로 가서 같은 사건 구간을 찍습니다.
    4. 작업을 마칠 때마다 CSV 내보내기 로 파일을 받아 담당자에게 보냅니다. 브라우저 저장소는 다른 컴퓨터 · 브라우저와 공유되지 않습니다.
