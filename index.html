    주변 프레임 경계 확인: 바로 앞 칸은 아직 가능, 표시한 칸부터 불가능

    작업자를 고르세요

    장면 단위 (pair1 · pair2 함께) 로 condition 마다 고르게 4 명에게 나눴습니다. 라벨은 이 브라우저에만 자동 저장되니, 같은 브라우저에서 이어서 작업하세요.

    표시 규칙

    1. 프레임 번호는 원본 60 fps 기준, 0 부터 (영상 시작 = 0). 화면 왼쪽 위 F 숫자가 그 번호입니다.
    2. 시작 = 위반이 처음 보이는 프레임. 사라지기 시작 · 바뀌기 시작 · 통과하기 시작 · 순간이동한 첫 프레임. 바로 앞 프레임까지는 아직 가능한 장면이어야 합니다.
    3. 끝 = 위반이 끝나는 프레임. 순간적인 사건이면 시작과 같게 (I).
    4. 위반이 가림막 뒤에서 일어나 드러나는 순간이 따로 있으면, 시작은 드러나는 프레임으로 하고 “가림 뒤” 를 체크합니다.
    5. 위반을 못 찾겠으면 비워 두고 “못 찾음” 체크 + 메모에 이유.

    condition 별로 보는 것

    작업 순서

    1. 1× 로 한 번 끝까지 보며 위반이 대략 어디인지 찾습니다.
    2. 그 근처에서 ← → 로 한 프레임씩 움직이며, 아래 주변 프레임 줄에서 “가능 → 불가능” 으로 바뀌는 경계를 찾습니다.
    3. S 로 시작, E 로 끝을 찍고, R 로 구간을 다시 재생해 확인합니다.
    4. Enter 로 다음 영상. 라벨은 자동 저장됩니다.
    5. 작업을 마칠 때마다 CSV 내보내기 로 파일을 받아 담당자에게 보냅니다. 브라우저 저장소는 다른 컴퓨터 · 브라우저와 공유되지 않습니다.
